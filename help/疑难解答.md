## 导入问题

### 问题 1: 无法导入歌曲

**症状**:
- 点击导入按钮后没有反应
- 文件选择器无法打开
- 选择文件后导入失败

**可能原因**:
1. 存储权限未授予
2. 文件格式不支持
3. 文件损坏

**解决方案**:

1. **检查存储权限**:
   - 进入手机设置 → 应用管理 → Purely Music
   - 点击"权限"
   - 确保"存储"权限已授予

2. **检查文件格式**:
   - Purely Music 支持：mp3、flac、wav、ogg、m4a、aac
   - 确保文件扩展名正确
   - 尝试使用支持的格式

3. **检查文件完整性**:
   - 尝试用其他播放器打开文件
   - 如果其他播放器也无法播放，文件可能已损坏

### 问题 2: 导入的歌曲无法播放

**症状**:
- 歌曲已导入但点击无法播放
- 播放按钮无反应
- 显示错误信息

**解决方案**:

1. **检查文件编码**:
   - 某些特殊编码的文件可能无法播放
   - 尝试使用音频转换工具转换为标准格式

2. **清理应用缓存**:
   - 手机设置 → 应用管理 → Purely Music
   - 点击"存储"
   - 点击"清除缓存"

3. **重启应用**:
   - 完全关闭 Purely Music
   - 重新打开应用

### 问题 3: 导入后歌曲信息显示错误

**症状**:
- 歌名、歌手信息错误
- 专辑封面显示为默认图片
- 歌词自动获取失败

**解决方案**:

1. **等待自动获取**:
   - 自动获取封面和歌词（在线获取）需要网络连接
   - 等待几秒钟让系统尝试获取

2. **手动获取**:
   - 长按歌曲卡片
   - 选择"刷新信息"
   - 系统会重新尝试获取

3. **手动添加歌词**:
   - 下载对应的 LRC 歌词文件
   - 将歌词文件命名为与歌曲相同的名称
   - 放置在同一目录下

## 播放问题

### 问题 4: 播放时出现卡顿

**症状**:
- 音乐播放不流畅
- 频繁出现暂停
- 进度条跳动

**解决方案**:

1. **关闭其他应用**:
   - 关闭后台运行的其他应用
   - 释放系统资源

2. **降低音效质量**:
   - 进入设置
   - 将音效设置为"无效果"
   - 减少系统负载

3. **重启手机**:
   - 完全重启手机
   - 清理系统缓存

### 问题 5: 无法暂停音乐

**症状**:
- 点击暂停按钮无效
- 音乐继续播放
- MiniPlayer 显示暂停但实际未暂停

**解决方案**:

1. **强制停止应用**:
   - 手机设置 → 应用管理 → Purely Music
   - 点击"强制停止"
   - 重新打开应用

2. **检查通知栏**:
   - 检查系统通知栏是否有播放控制
   - 尝试使用通知栏暂停

3. **重启手机**:
   - 完全重启手机

### 问题 6: 切换歌曲失败

**症状**:
- 点击下一首/上一首无反应
- 一直重复播放同一首歌
- 无法跳转到指定歌曲

**解决方案**:

1. **检查播放列表**:
   - 确保播放列表中有歌曲
   - 如果只有一首歌，自然无法切换

2. **检查播放模式**:
   - 如果在"单曲循环"模式，会重复播放当前歌曲
   - 切换到"顺序播放"模式

3. **手动选择歌曲**:
   - 进入资料库
   - 直接点击想播放的歌曲

### 问题 7: 进度条无法拖动

**症状**:
- 拖动进度条无反应
- 释放后回到原位置
- 无法调整播放位置

**解决方案**:

1. **重新点击播放**:
   - 暂停播放
   - 重新点击播放
   - 再尝试拖动进度条

2. **重启应用**:
   - 完全关闭并重新打开应用

3. **检查文件**:
   - 某些流媒体格式的文件可能不支持进度拖动
   - 尝试其他格式的文件

## 歌词问题

### 问题 8: 歌词不显示

**症状**:
- 播放界面看不到歌词
- 点击封面无反应
- 歌词区域空白

**解决方案**:

1. **检查歌词文件**:
   - 确保歌曲目录中有对应的 LRC 文件
   - 文件名应与歌曲文件名相同（不含扩展名）

2. **检查歌词格式**:
   - 歌词必须是标准的 LRC 格式
   - 每行格式：`[时间]歌词内容`
   - 例如：`[00:12.34]这是一行歌词`

3. **检查歌词编码**:
   - 歌词文件应使用 UTF-8 或 GBK 编码
   - 应用会自动尝试两种编码

4. **等待自动获取**:
   - 如果没有本地歌词，应用会尝试自动获取
   - 需要网络连接
   - 等待几秒钟

### 问题 9: 歌词不同步

**症状**:
- 歌词与播放进度不匹配
- 歌词显示过快或过慢
- 当前歌词高亮位置错误

**解决方案**:

1. **检查歌词文件**:
   - 确保歌词文件中的时间标签正确
   - 使用专业的歌词编辑工具修复

2. **调整歌词偏移**:
   - 目前版本不支持歌词偏移调整
   - 需要手动编辑歌词文件中的时间

3. **使用正确的歌词版本**:
   - 不同版本的歌词时间可能不同
   - 下载与当前歌曲版本匹配的歌词

### 问题 10: 歌词显示乱码

**症状**:
- 歌词显示为乱码字符
- 中文显示为问号或方框
- 特殊字符无法显示

**解决方案**:

1. **检查歌词编码**:
   - 将歌词文件转换为 UTF-8 编码
   - 使用文本编辑器打开并另存为 UTF-8

2. **手动转换编码**:
   - Windows 记事本：另存为 → 编码选择 UTF-8
   - Mac 文本编辑：格式 → 制作纯文本 → UTF-8

### 问题 11: 歌词过滤功能无效

**症状**:
- 开启"过滤敏感词"后，敏感词仍然显示
- 过滤效果不明显

**解决方案**:

1. **检查设置**:
   - 进入设置 → 歌词
   - 确保"过滤敏感词"已开启

2. **重启应用**:
   - 关闭应用
   - 重新打开
   - 设置会生效

3. **敏感词库**:
   - 过滤功能使用内置敏感词库
   - 某些生僻词可能未被收录

## 翻译问题

### 问题 12: 翻译按钮不显示

**症状**:
- 歌词界面没有翻译按钮
- 无法点击翻译
- 按钮为灰色

**可能原因**:
1. 歌词已经是中文
2. 没有网络连接
3. 翻译 API 未配置

**解决方案**:

1. **检查歌词语言**:
   - 翻译功能仅针对非中文歌词
   - 如果歌词已经是中文，不会显示翻译按钮

2. **检查网络连接**:
   - 确保设备已连接网络
   - 尝试打开浏览器访问网页

3. **配置翻译 API**:
   - 查看 TRANSLATION_API_NOTE.md 文件
   - 按照说明配置翻译 API

### 问题 13: 翻译失败

**症状**:
- 点击翻译后显示错误
- 翻译结果为空
- 显示"翻译失败"提示

**解决方案**:

1. **查看翻译日志**:
   - 进入设置 → 日志
   - 点击"查看翻译日志"
   - 查看详细错误信息

2. **检查 API 配置**:
   - 确保翻译 API 已正确配置
   - API Key 是否有效
   - 是否有足够的调用次数

3. **检查网络**:
   - 确保网络连接稳定
   - 尝试使用 WiFi 而非移动数据

4. **重试翻译**:
   - 等待几分钟后再次尝试
   - 可能是 API 服务暂时不可用

### 问题 14: 翻译质量差

**症状**:
- 翻译结果不准确
- 语法错误
- 词不达意

**解决方案**:

1. **了解限制**:
   - 自动翻译无法达到人工翻译的质量
   - 某些诗歌、隐喻难以准确翻译

2. **尝试其他歌词版本**:
   - 不同来源的歌词可能翻译效果不同
   - 尝试使用其他歌词网站获取歌词

3. **反馈问题**:
   - 如果翻译错误明显，欢迎反馈
   - 帮助我们改进翻译质量

## 音效问题

### 问题 15: 音效无效

**症状**:
- 切换音效后无变化
- 听起来没有区别
- 设置后立即恢复默认

**解决方案**:

1. **检查音效设置**:
   - 进入设置 → 音效
   - 确保选择了音效模式

2. **重新开始播放**:
   - 暂停播放
   - 重新点击播放
   - 音效会重新应用

3. **重启应用**:
   - 完全关闭并重新打开应用

### 问题 16: 音效有杂音

**症状**:
- 音效伴随杂音
- 爆音或破音
- 音质下降

**解决方案**:

1. **降低音量**:
   - 将系统音量降低到中等水平
   - 避免音量过大导致破音

2. **切换音效**:
   - 尝试不同的音效模式
   - 某些音效可能在特定歌曲上表现不佳

3. **关闭音效**:
   - 选择"无效果"模式
   - 使用原始音质

4. **检查音频文件**:
   - 确保音频文件质量良好
   - 低质量的文件可能不适合音效处理

### 问题 17: 立体声/环绕效果不明显

**症状**:
- 听不到立体声效果
- 环绕音效不明显
- 声音感觉是单声道

**解决方案**:

1. **使用耳机**:
   - 外放时立体声效果不明显
   - 使用耳机获得最佳效果

2. **检查歌曲**:
   - 确保歌曲本身是立体声录制
   - 某些老歌是单声道

3. **调整位置**:
   - 3D 环绕效果需要声源移动
   - 耐心听几秒钟感受效果

## 界面问题

### 问题 18: 界面卡顿

**症状**:
- 滑动不流畅
- 按钮响应慢
- 动画卡顿

**解决方案**:

1. **关闭其他应用**:
   - 关闭后台运行的应用
   - 释放系统内存

2. **清理应用缓存**:
   - 手机设置 → 应用管理 → Purely Music
   - 清除缓存

3. **降低动画效果**:
   - 手机设置 → 开发者选项
   - 降低动画缩放级别

### 问题 19: 界面显示异常

**症状**:
- 元素显示错位
- 字体显示异常
- 颜色显示错误

**解决方案**:

1. **重启应用**:
   - 完全关闭并重新打开

2. **检查系统语言**:
   - Purely Music 支持中文和英文
   - 其他语言可能导致显示异常

3. **重新安装应用**:
   - 备份数据（播放列表等）
   - 卸载应用
   - 重新安装

### 问题 20: 无法进入设置

**症状**:
- 点击设置无反应
- 设置页面空白
- 设置选项无法点击

**解决方案**:

1. **强制停止应用**:
   - 完全关闭应用
   - 重新打开

2. **清理应用数据**:
   - **警告**: 此操作会删除所有设置和导入的歌曲
   - 手机设置 → 应用管理 → Purely Music
   - 清除数据
   - 重新配置应用

## 性能问题

### 问题 21: 应用占用空间过大

**症状**:
- 应用占用数百 MB 甚至 GB 空间
- 手机存储不足
- 导入后可用空间明显减少

**解决方案**:

1. **了解机制**:
   - 导入的音乐会被复制到应用目录
   - 这是正常行为，避免权限问题

2. **管理歌曲**:
   - 删除不需要的歌曲
   - 使用低质量的音频文件（如有必要）

3. **清理应用数据**:
   - 删除应用并重新安装
   - **警告**: 会删除所有歌曲和设置

### 问题 22: 电池消耗快

**症状**:
- 使用应用时电池快速消耗
- 发热严重

**解决方案**:

1. **关闭音效**:
   - 音效处理会增加 CPU 负载
   - 选择"无效果"模式

2. **降低屏幕亮度**:
   - 在播放器界面降低亮度

3. **关闭其他功能**:
   - 关闭歌词发光特效
   - 关闭自动获取封面和歌词

4. **检查后台**:
   - 确保没有其他应用在后台运行

### 问题 23: 应用崩溃

**症状**:
- 应用意外关闭
- 显示"应用已停止"
- 频繁崩溃

**解决方案**:

1. **检查内存**:
   - 关闭其他应用释放内存
   - 重启手机

2. **清理缓存**:
   - 清除应用缓存

3. **检查存储空间**:
   - 确保手机有足够的存储空间
   - 至少保留 500MB 可用空间

4. **更新应用**:
   - 检查是否有新版本
   - 更新到最新版本

5. **反馈问题**:
   - 如果问题持续，请通过 GitHub 反馈
   - 提供详细的崩溃信息

## 其他问题

### 问题 24: 如何完全删除应用数据？

**步骤**:
1. 手机设置 → 应用管理 → Purely Music
2. 点击"存储"
3. 点击"清除数据"

**注意**: 此操作会删除：
- 所有导入的歌曲
- 所有播放列表
- 所有设置
- 翻译日志

### 问题 25: 如何备份和恢复数据？

**当前限制**: 应用暂不支持自动备份功能

**手动备份**:
1. 使用文件管理器复制应用目录
2. 位置：`/Android/data/com.music.purelymusic/files/`

**恢复**:
1. 将备份的文件复制回原位置
2. 重启应用

### 问题 26: 是否支持云端同步？

**当前状态**: 不支持

**未来计划**: 可能会在后续版本中添加云端同步功能

### 问题 27: 如何更新应用？

**方法**:
1. GitHub Releases 页面
2. 下载最新版本的 APK 文件
3. 安装更新（会覆盖旧版本，保留数据）

### 问题 28: 支持哪些音频格式？

**支持的格式**:
- MP3
- FLAC
- WAV
- OGG
- M4A
- AAC

**不支持的格式**:
- APE（考虑未来支持）
- DSD
- 其他专业音频格式

**联系方式**:

- 错误日志（如有）
