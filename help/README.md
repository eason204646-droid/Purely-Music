### 🔧 疑难解答.md
**常见问题与解决方案**
- 导入问题（无法导入、无法播放、信息错误）
- 播放问题（卡顿、无法暂停、切换失败）
- 歌词问题（不显示、不同步、乱码）
- 翻译问题（按钮不显示、翻译失败、质量差）
- 音效问题（无效、杂音、效果不明显）
- 界面问题（卡顿、显示异常、无法进入设置）
- 性能问题（占用空间大、电池消耗快、应用崩溃）
- 其他问题（数据备份、云端同步、音频格式支持）

**适合**: 遇到问题需要解决方案的用户

## 如何使用这些文档

### 在应用中查看

1. 打开 Purely Music 应用
2. 进入"设置"页面
3. 点击"帮助"栏目
4. 选择相应的文档查看

### 在本地查看

这些 Markdown 文件可以直接在任何支持 Markdown 的阅读器中打开：

- VS Code
- Typora
- Markdown Pad
- 在线 Markdown 编辑器

### 在 GitHub 上查看

您也可以在 GitHub 项目仓库中查看这些文档：

https://github.com/eason204646-droid/Purely-Music
