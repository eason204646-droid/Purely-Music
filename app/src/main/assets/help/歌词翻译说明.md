# Purely Music 歌词翻译功能说明

## 功能概述

### 什么是歌词翻译？

歌词翻译功能是 Purely Music 的一项智能功能，能够：

- **自动检测歌词语言** - 识别歌词是否为中文
- **实时翻译** - 将非中文歌词翻译成中文
- **双语显示** - 同时显示原文和翻译
- **保持同步** - 翻译结果与歌词时间同步

### 翻译支持的特性

✅ **多语言支持** - 支持英语、日语、韩语等多种语言
✅ **实时翻译** - 点击即可翻译，无需等待
✅ **双语对照** - 原文和翻译对照显示
✅ **时间同步** - 翻译结果与歌词完美同步
✅ **错误处理** - 完善的错误处理和重试机制
✅ **日志记录** - 详细的翻译日志便于排查问题

## 使用方法

### 基本使用步骤

#### 1. 播放歌曲

首先确保您已经：

- 导入了歌曲到 Purely Music
- 歌曲有对应的歌词文件
- 歌词已成功加载

#### 2. 切换到歌词视图

在播放界面：

- 点击专辑封面切换到歌词视图
- 确认歌词已正确显示
- 检查歌词是否为非中文语言

#### 3. 检查翻译按钮

如果歌词为非中文语言：

- 歌词界面右上角会出现翻译按钮
- 翻译按钮图标为翻译图标
- 按钮颜色为主题红色

**注意**: 如果歌词已经是中文，不会显示翻译按钮。

#### 4. 执行翻译

点击翻译按钮开始翻译：

1. 点击翻译按钮
2. 应用会显示"正在翻译"提示
3. 等待翻译完成（通常 2-5 秒）
4. 翻译完成后会显示双语歌词

#### 5. 查看翻译结果

翻译完成后：

- 歌词区域会显示双语
- 上方为原文
- 下方为中文翻译
- 当前歌词高亮显示

### 翻译状态说明

翻译过程中可能出现的几种状态：

#### 翻译中

- **显示**: "正在翻译..."提示
- **图标**: 翻译按钮禁用（灰色）
- **操作**: 等待翻译完成

#### 翻译成功

- **显示**: 双语歌词显示
- **图标**: 翻译按钮保持激活状态
- **操作**: 可以继续播放或查看

#### 翻译失败

- **显示**: 错误提示信息
- **图标**: 翻译按钮恢复可用
- **操作**: 查看日志了解详情，重试翻译

### 翻译开关

当前版本中，翻译功能需要手动触发。未来版本可能会添加：

- 自动翻译选项
- 翻译语言选择
- 翻译缓存管理

## API 配置

### 为什么需要配置？

Purely Music 的翻译功能依赖第三方翻译 API，需要：

- API Key（密钥）
- 有效的 API 账户
- 足够的调用次数

### 获取 API Key

#### 步骤 1: 注册 API 服务

Purely Music 使用翻译 API 服务，您需要：

1. 访问翻译服务提供商网站
2. 注册账户
3. 获取 API Key

#### 步骤 2: 配置 API Key

在 Purely Music 项目中配置 API Key：

1. 打开项目文件 `app/build.gradle.kts`
2. 找到 `buildConfigField` 配置
3. 添加 API Key 配置

**示例配置**:
```kotlin
buildConfigField("String", "MUSIC_API_KEY", "\"your_api_key_here\"")
```

#### 步骤 3: 重新编译

配置完成后：

1. 清理项目（Build → Clean Project）
2. 重新编译（Build → Rebuild Project）
3. 安装更新后的应用

### API 费用说明

不同的翻译服务提供商有不同的计费方式：

- **免费额度**: 大多数服务提供每月免费调用次数
- **按量付费**: 超出免费额度后按调用次数计费
- **套餐订阅**: 可以购买固定调用次数的套餐

**建议**:
- 优先选择有免费额度的服务
- 根据使用量选择合适的套餐
- 定期检查 API 使用情况

### 推荐的翻译服务

以下是常用的翻译 API 服务：

1. **百度翻译 API**
   - 免费额度：每月 5 万字符
   - 优点：中文翻译质量好
   - 缺点：需要实名认证

2. **腾讯翻译君 API**
   - 免费额度：每月 500 万字符
   - 优点：额度大，速度快
   - 缺点：需要企业认证

3. **有道翻译 API**
   - 免费额度：每月 100 万字符
   - 优点：翻译准确
   - 缺点：需要申请审核

4. **Google Translate API**
   - 免费额度：每月 50 万字符
   - 优点：支持语言多
   - 缺点：需要国际信用卡

### 安全注意事项

配置 API Key 时请注意：

✅ **不要在公开代码中暴露 API Key**
✅ **使用版本控制时忽略包含 API Key 的文件**
✅ **定期更换 API Key**
✅ **监控 API 使用情况**
✅ **设置 API Key 使用限制**

**建议做法**:
- 使用 `local.properties` 文件存储 API Key
- 将 `local.properties` 添加到 `.gitignore`
- 在文档中提供配置示例

## 翻译效果

### 翻译质量

翻译质量取决于多个因素：

#### 1. 源歌词质量

- **清晰语法**: 语法正确的歌词翻译效果更好
- **标准词汇**: 常用词汇翻译更准确
- **完整句子**: 完整的句子比片段翻译效果更好

#### 2. 歌词类型

不同类型的歌词翻译效果不同：

- **流行音乐**: 通常翻译效果较好
- **古典音乐**: 可能需要专业术语
- **诗歌风格**: 可能保留原意
- **俚语口语**: 可能翻译不准确

#### 3. 语言对

不同语言对的翻译难度不同：

- **英语 → 中文**: 翻译质量较好
- **日语 → 中文**: 翻译质量良好
- **韩语 → 中文**: 翻译质量良好
- **小语种 → 中文**: 翻译质量一般

### 翻译示例

以下是一些翻译示例：

#### 示例 1: 英语歌词

**原文**:
```
[00:12.34]Yesterday all my troubles seemed so far away
[00:17.89]Now it looks as though they're here to stay
[00:23.45]Oh, I believe in yesterday
```

**翻译**:
```
[00:12.34]昨天，我所有的烦恼似乎都很遥远
[00:17.89]现在看来它们似乎要留在这里
[00:23.45]哦，我相信昨天
```

#### 示例 2: 日语歌词

**原文**:
```
[00:08.15]君がいない世界は
[00:12.30]色彩を失っていく
[00:16.45]心の奥深くに
[00:20.60]永遠の記憶が刻まれる
```

**翻译**:
```
[00:08.15]没有你的世界
[00:12.30]正在失去色彩
[00:16.45]在心灵深处
[00:20.60]刻下永恒的记忆
```

### 翻译限制

请了解以下翻译限制：

1. **无法达到人工翻译质量** - 自动翻译无法完全替代人工翻译
2. **诗歌和隐喻难以准确翻译** - 文学性强的歌词可能失去原意
3. **文化差异** - 某些文化特有的表达可能无法完美翻译
4. **专业术语** - 专业领域的歌词可能翻译不准确

## 常见问题

### Q1: 为什么我的歌曲没有翻译按钮？

**A**: 可能的原因：
1. 歌词已经是中文，不需要翻译
2. 歌词文件未正确加载
3. 歌词语言检测失败
4. API 未配置

**解决方案**:
- 确认歌词是否为非中文语言
- 检查歌词文件是否正确
- 查看 API 配置是否正确

### Q2: 翻译后显示乱码怎么办？

**A**: 可能的原因：
1. 翻译 API 返回编码问题
2. 歌词文件编码问题
3. 应用显示问题

**解决方案**:
- 查看翻译日志了解详情
- 尝试重新翻译
- 检查歌词文件编码

### Q3: 翻译速度很慢怎么办？

**A**: 可能的原因：
1. 网络连接慢
2. API 服务器响应慢
3. 歌词内容过长

**解决方案**:
- 检查网络连接
- 尝试使用 WiFi
- 等待翻译完成

### Q4: 翻译结果不准确怎么办？

**A**: 可能的原因：
1. 源歌词质量不高
2. 歌词类型特殊（诗歌、俚语等）
3. API 翻译质量限制

**解决方案**:
- 理解自动翻译的局限性
- 尝试其他歌词版本
- 提供反馈帮助改进

### Q5: 翻译次数有限制吗？

**A**: 是的，翻译次数受限于：
1. API 提供商的免费额度
2. 您的 API 套餐限制
3. API Key 的使用限制

**解决方案**:
- 检查 API 使用情况
- 升级 API 套餐
- 合理使用翻译功能

### Q6: 如何查看翻译历史？

**A**: 当前版本不支持翻译历史查看。

**建议**:
- 查看翻译日志
- 记录重要的翻译结果
- 未来版本可能添加此功能

## 故障排除

### 问题 1: 点击翻译按钮无反应

**检查步骤**:

1. **检查网络连接**
   - 确保设备已连接网络
   - 尝试打开浏览器访问网页

2. **检查 API 配置**
   - 确认 API Key 已正确配置
   - 验证 API Key 是否有效
   - 检查 API 调用次数是否已用尽

3. **查看翻译日志**
   - 进入设置 → 日志
   - 点击"查看翻译日志"
   - 查看详细错误信息

4. **重启应用**
   - 完全关闭应用
   - 重新打开应用
   - 再次尝试翻译

### 问题 2: 翻译失败，显示错误信息

**常见错误及解决方案**:

#### 错误: "API Key 无效"

**原因**: API Key 配置错误或已失效

**解决方案**:
1. 检查 API Key 是否正确
2. 重新获取有效的 API Key
3. 更新项目配置并重新编译

#### 错误: "API 调用次数超限"

**原因**: 已超过免费调用次数

**解决方案**:
1. 等待下个月额度重置
2. 升级 API 套餐
3. 使用其他 API 服务

#### 错误: "网络连接失败"

**原因**: 网络连接问题

**解决方案**:
1. 检查网络连接
2. 尝试使用 WiFi
3. 检查防火墙设置

#### 错误: "歌词格式错误"

**原因**: 歌词文件格式不正确

**解决方案**:
1. 检查歌词文件是否为标准 LRC 格式
2. 确保歌词文件编码正确
3. 尝试重新下载歌词文件

### 问题 3: 翻译结果不显示

**检查步骤**:

1. **确认翻译成功**
   - 查看是否有错误提示
   - 检查翻译日志

2. **刷新歌词视图**
   - 切换回封面视图
   - 再次切换到歌词视图

3. **重启应用**
   - 完全关闭应用
   - 重新打开应用

4. **重新导入歌曲**
   - 删除歌曲
   - 重新导入
   - 再次尝试翻译

## 技术细节

### 翻译流程

Purely Music 的翻译流程如下：

```
1. 用户点击翻译按钮
   ↓
2. 检查歌词语言
   ↓
3. 构建翻译请求
   ↓
4. 发送到翻译 API
   ↓
5. 接收翻译结果
   ↓
6. 解析翻译文本
   ↓
7. 匹配歌词时间
   ↓
8. 更新歌词显示
   ↓
9. 显示双语歌词
```

### API 请求格式

Purely Music 发送的翻译请求包含：

- **API Key**: 认证密钥
- **文本**: 歌词内容（包含时间标签）
- **源语言**: 自动检测（auto）
- **目标语言**: 中文（zh）

### 响应处理

API 响应处理步骤：

1. **验证响应状态码**
2. **检查返回数据**
3. **解码 HTML 实体**
4. **解析翻译文本**
5. **匹配歌词时间**
6. **更新歌词对象**

### 日志记录

翻译日志记录以下信息：

- 翻译请求时间
- API 响应状态
- 翻译结果摘要
- 错误详情（如有）
- 处理耗时

### 性能优化

为提高翻译性能，Purely Music 采用了：

1. **异步处理** - 使用 Kotlin Coroutines
2. **批量翻译** - 一次性翻译整首歌词
3. **错误重试** - 自动重试失败的请求
4. **缓存机制** - 未来版本将添加
