几件关于安装与日常使用的小事。

我的设备可以安装吗？

需要 Android 8.0（API 26）或更高版本。前往 GitHub Releases，选择已发布版本的 APK 下载并安装。安装包与更新说明以发布页面为准。

听音乐需要联网吗？

播放已经导入的本地音乐不依赖网络。自动获取封面、歌词和非中文歌词翻译需要联网，且安装包需要配置相应服务。自行构建时，按 README 在 local.properties 中配置 MUSIC_API_KEY。没有配置密钥，也可以正常本地播放。

导入的音乐会保存在哪里？

导入的音频、封面和歌词保存在应用私有存储中。请保留原始音乐文件，卸载应用前另行备份，避免随应用数据删除而丢失收藏。

智能混音和交叉渐变有什么区别？

智能混音会分析曲目片段，尝试匹配节拍与调性，并选择合适的衔接方式；不适合处理时，继续普通播放。交叉渐变使用你设定的固定时长，让前后曲目渐出、渐入。两者是可选的自动切歌方式，可在播放设置中选择。
